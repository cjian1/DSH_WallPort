# examples —— 可以直接拿来用的模板

这个目录里的东西是给「使用者」和「想写模板的人」看的，不参与插件运行。

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| `minimal-template.html` | **最小骨架（带逐步注释）**：一段自包含 HTML，演示怎么铺满全屏、怎么读真实启动进度、拿不到桥接时怎么降级 | 复制一份改一改，再按下面的方式导入 |
| `aurora-drift.json` | 一个**真的由 AI 生成**的模板（极光漂移），插件存储格式 | 设置 → 外观 → 开机动画 → 「手动导入模板」，把整个 JSON 粘进去 |
| `neon-scan.json` | 同样由 AI 生成（赛博霓虹：紫粉光带 + 扫描线 + 网格地平线） | 同上 |

## 导入示例模板

1. 打开 设置 → 外观 → **开机动画**；
2. 拉到「手动导入模板」，把 `aurora-drift.json` 或 `neon-scan.json` 的**全文**粘进输入框；
3. 点「导入并启用」——它会被存成自定义模板（同名会覆盖），并立刻成为当前开机动画；
4. 刷新页面即可看到（刚装好插件后的第一次需要重启一次 DSH）。

## 只看不装

```bash
node tools/preview.mjs --file examples/neon-scan.json
node tools/preview.mjs --examples        # 内置 7 个 + 这里的示例，全部导出到 previews/
```

导出的 HTML 用浏览器直接打开就会循环播放（带模拟进度）。
