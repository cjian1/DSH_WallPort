# 用 AI 自定义开机动画 · 用户指南

给**使用者**（不是开发者）看的：怎么让 DSH 里的 AI 帮你把开机动画做出来、换上去、再改到满意。

---

## 0. 前置

插件装好后（插件管理里能看到「开机动画」），**重启一次 DSH** 让启动注入生效。
之后：换模板 → 刷新页面就能看到；关闭动画 → 需要重启一次。

---

## 1. 最省事的用法：说一句话

在**任意会话**里直接说人话，AI 会自己调用插件提供的工具：

> 把开机动画换成赛博霓虹风格的，紫粉色光带 + 扫描线，节奏快一点

AI 接下来会（不需要你指导）：

1. `boot_animation_list` 看一眼现在有哪些模板；
2. 写一段自包含 HTML 动画，用 `boot_animation_save` 存成自定义模板并启用；
3. 用 `boot_animation_preview` 导出一份预览文件，把路径告诉你；
4. 告诉你当前生效的是哪个模板。

**你要做的**：打开预览看一眼 → 满意就刷新页面；不满意就继续说，比如
「再亮一点」「速度快一点」「字标换成『深度求索』」「背景换成浅色」。

## 2. 最稳的用法：在设置页里写好，再复制提示词

如果你想让 AI 一次做对（尤其是它不熟悉这个插件时）：

1. 打开 设置 → 外观 → **开机动画** → 「用 AI 自定义」卡片；
2. 在 **「① 我想要的开机动画（在这里打字）」** 输入框里写下你的描述——
   这是真正的输入框，直接打字就行；下面的提示词会**实时**带上你写的内容；
3. 点 **「复制提示词给 AI」**，整段粘贴到任意对话里发送。

不想自己想？点下面三句示例中的任意一句，它会**填进输入框**，你可以先改再复制。

这段提示词里已经把工具名、模板格式、真进度 API、体积与时长约束都写清楚了，
所以 AI 不需要额外摸索。

（剪贴板被系统挡住时，下面的提示词框可以手动选中复制；输入框里的内容你自己也看得到。）

## 3. 卡片上的三条示例

设置页里点任意一句会**填进输入框**（不是只复制），你可以先改再复制提示词：

- 把开机动画换成赛博霓虹风格：紫粉色光带 + 扫描线，节奏快一点
- 做一个水墨风的开机动画，浅色底、墨点扩散，落款写「深度求索」
- 把现在的开机动画改成极简风，只留一条微光进度线

## 4. 一次典型对话

| 你说 | AI 做 |
|---|---|
| 「我想要一个深海探测主题的开机动画」 | `boot_animation_list` → 写动画 → `boot_animation_save`（启用）→ `boot_animation_preview` → 给你预览路径 |
| 「蓝色再深一点，光带慢一些」 | 改写 document → 再 `boot_animation_save`（同名覆盖）→ 再导出一份预览 |
| 「换回系统自带的那个」 | `boot_animation_apply` 切到 `deepseek-pulse`（或任意内置模板） |
| 「这几个都不想要了」 | `boot_animation_remove` 删掉自定义模板（内置的删不掉） |
| 「动画太长/太短」 | `boot_animation_settings` 改最短/兜底时长、是否可跳过 |

## 5. 预览怎么看

- **设置页里**：模板卡片点「预览」，弹窗里循环播放并模拟启动进度；
- **独立文件**：AI 用 `boot_animation_preview` 导出的 HTML 文件，双击用浏览器打开即可
  （路径通常在 `$DSH_HOME/dsh-wallport/previews/<id>.html`）；
- 不装插件也能看内置模板：在插件目录里跑 `node tools/preview.mjs --all`。

## 6. 生效时机（重要）

| 动作 | 什么时候看到 |
|---|---|
| 换模板 / 改时长 / 改是否可跳过 | 刷新 DSH 页面即可（桌面版也一样，插件会现场核对一次当前设置） |
| **刚装好插件后的第一次** | 需要重启一次 DSH：启动注入表是宿主启动时生成的 |
| 关闭开机动画 | 需要重启一次 DSH（关闭意味着连注入行都不再下发） |

## 7. 不满意怎么办

- **描述再具体一点**：颜色、材质、节奏、要不要文字、像什么（"像深海探测器下潜"比"蓝色"有用）；
- **直接点名内置模板**：`terminal-boot`（终端）、`starfield`（星野）、`matrix-rain`（代码雨）、
  `orbit`（轨道）、`minimal-fade`（极简）、`ink-wash`（水墨）、`deepseek-pulse`（默认）；
- **让 AI 先预览再启用**：说「先别启用，导个预览给我看看」；
- **手动兜底**：设置页「手动导入模板」可以直接粘一段 JSON 或一整段 HTML。

## 8. 常见问题

**换了没反应？**
先刷新页面；如果这是装好插件后的第一次，重启一次 DSH。

**设置页里输入框打不了字？**
输入框是真输入框（受控组件），可以直接打字；如果毫无反应，先刷新一次页面拿到最新版本的插件前端
（老版本那一块只有一段只读的提示词，没有输入框）。

**AI 说找不到工具？**
说明插件没在这个 profile 里生效：去 设置 → 插件 里确认「开机动画」是启用状态，然后重启 DSH。

**AI 生成的动画不好看/太吵？**
这类动画是纯 HTML/CSS/JS 写的，改起来很快：把你的意见说清楚让它改，或者先切回 `minimal-fade` 这类安静的模板。

**会收集我的数据吗？**
不会。模板与设置都存在本机 `$DSH_HOME/dsh-wallport/`，动画不联网。
唯一的外部交互是你和 AI 的对话本身。

**有安全风险吗？**
模板是在同源 iframe 里执行的普通网页代码，和一个已安装插件同级。所以：
只用你自己（或你信任的 AI 会话）生成的模板，来源不明的模板先预览再启用。

**体积/性能？**
单个模板上限 512 KiB；开机动画默认最短展示 1.2s、最长 12s，到点一定让位给界面。

## 附：AI 需要遵守的模板契约

（也就是「复制完整提示词」里那段要求，方便你手写或转述）

1. 用 `boot_animation_save` 保存，`id` 用小写字母/数字/连字符，`activate: true` 直接启用；
2. `document` 是一段自包含 HTML（可内联 `<style>/<script>`，也可以是完整文档）：
   铺满全屏、不要滚动，**不依赖任何网络资源**；
3. 想跟随真实启动进度就用 `window.dshBootAnim`：
   `progress()`（0…1）、`on('progress', fn)`、`isReady()`、`on('ready', fn)`、`reduced()`；
4. 颜色/字体自带——开机阶段 DSH 的 CSS 变量还没加载；
5. 时长由插件统一控制，动画自己循环播放，不需要自己结束；
6. 保存后用 `boot_animation_preview` 导出预览；想换/删分别用 `boot_animation_apply` / `boot_animation_remove`。
